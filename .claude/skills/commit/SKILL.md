# Commit 스킬

코드 변경사항을 분석하여 의도를 명확히 드러내는 커밋을 생성하도록 돕는 스킬입니다.

## 절차

### 1단계: 변경사항 분석

먼저 현재 상태를 파악합니다:

```bash
git status
git diff --stat
git diff
```

무엇이 변경되었는지, 어떤 파일들이 영향받았는지 확인합니다.

### 2단계: 논리적 단위로 분류

변경사항을 검토하면서 다음을 판단합니다:

- **단일 커밋이 적합한가?** 변경사항이 하나의 논리적 목표를 달성하면 하나의 커밋
- **분리가 필요한가?** 서로 다른 기능, 버그 수정, 리팩토링이 섞여 있으면 분리 제안

예를 들어:
- 기능 A 추가 + 기능 A 테스트 → 함께 커밋 가능
- 기능 A 추가 + 버그 B 수정 → 별개의 커밋으로 분리

### 3단계: 커밋 메시지 작성

한국어 커밋 메시지를 다음 형식으로 작성합니다:

```
<타입>(<범위>): <제목>

<본문(선택사항)>
```

**타입:**
- `feat` - 새로운 기능
- `fix` - 버그 수정
- `refactor` - 기능 변경 없는 코드 구조 개선
- `chore` - 도구, 설정, 의존성 변경
- `docs` - 문서 추가/수정
- `test` - 테스트 추가/수정
- `perf` - 성능 개선

**제목 작성:**
- 명령형 현재형 사용: "add" (O), "added" (X)
- 첫 글자는 소문자
- 마침표 없음
- 50자 이내

**본문 (필요시):**
- 왜 변경했는지 설명 (무엇을 변경했는지 아님)
- 72자 기준으로 줄바꿈

**예시:**

```
feat(auth): JWT 기반 사용자 인증 구현

사용자 로그인/로그아웃 기능을 추가합니다.
- access token 발급 및 검증
- refresh token을 통한 토큰 갱신
- 보호된 경로의 인증 미들웨어

이전의 session 기반 방식보다
상태 비저장 구조로 확장성이 향상됩니다.
```

### 4단계: 파일 목록 확인

커밋할 파일들을 확인합니다:

```
변경될 파일:
- src/auth/login.ts
- src/auth/token.ts
- tests/auth.test.ts
```

민감한 정보(`.env`, 키 파일, API 키, 비밀번호 등)가 포함되어 있으면
해당 파일은 커밋에서 제외하고 사용자에게 알립니다. 이 경우에만 진행을 멈추고
사용자에게 확인을 구합니다.

### 5단계: 커밋 실행

사용자 승인을 기다리지 않고 바로 커밋을 실행합니다:

```bash
git add <파일들>
git commit -m "<메시지>"
```

### 6단계: 완료 확인

커밋 후 결과를 출력합니다:

```bash
git log --oneline -1
```

## 특별한 경우들

### 여러 논리적 변경사항

```
변경사항 분석:
1. 사용자 인증 추가 (feat)
2. 로깅 시스템 개선 (refactor)

이들은 서로 독립적이므로 2개의 커밋으로 분리하여 순서대로 실행합니다:

커밋 1: feat(auth): 사용자 인증 구현
커밋 2: refactor(logging): 로깅 시스템 개선
```

### 커밋할 것이 없는 경우

변경사항이 없으면 명확하게 알립니다:

```
git status: 커밋할 변경사항이 없습니다.
```

### 스테이징되지 않은 파일

기본적으로 변경된 모든 파일을 자동으로 커밋합니다.
사용자가 특정 파일만 커밋해달라고 명시적으로 요청한 경우에만
해당 파일들로 범위를 좁혀 진행합니다.

## 주의사항

- **이미 커밋된 코드는 수정하지 않습니다.** 최신 변경사항만 처리
- **별도의 승인 절차 없이 바로 커밋을 실행합니다.** 사용자가 이 스킬을 
  호출한 것 자체가 커밋 실행에 대한 동의로 간주합니다
- **민감한 파일은 예외입니다.** `.env`, 키 파일 등 민감한 정보가 포함된 
  경우에는 자동 커밋하지 않고 반드시 사용자에게 확인을 구합니다
- **적절한 범위** - 하나의 커밋은 하나의 논리적 단위여야 함

## 출력 포맷

최종 결과는 다음과 같이 표시합니다:

```
✓ 커밋 완료
해시: abc1234
메시지: feat(auth): JWT 기반 사용자 인증 구현
변경된 파일: 3개
줄 변경: +45 -12
```
